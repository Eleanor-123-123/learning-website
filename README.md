# Film Review Website

This is the Web Technologies learning website.

## Open the website

The shared navigation is loaded with JavaScript `fetch()`, so the site must run through a local server.

1. Open the `my-site` folder in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Choose **Open with Live Server**.

The address should begin with `http://`, not `file://`.

## Pages

- `index.html` — homepage and site overview
- `quotes.html` — fifteen film quotations and a random quote hero
- `project.html` — five possible project ideas
- `machine.html` — an interactive useless machine

The navigation is written once in `nav.html` and loaded into every page by `nav.js`.
